  4. GopherAI 全栈 AI 应用平台（个人项目 · Go + Vue）

    基于 Go + Gin 构建的全栈 AI 应用平台，集成智能对话、RAG 知识库问答与图像识别能力，前后端分离并容器化部署，覆盖「用户请求 → 后端处理 → 检索增强 / AI 推理 → 数据落库 → 前端实时展示」的全链路。

    • AI 对话服务：接入通义千问等 LLM，支持多轮对话与 SSE 流式输出，通过 RabbitMQ 异步持久化会话消息，实现解耦、削峰与高吞吐；

    • 图像识别服务：基于 ONNX Runtime 加载 MobileNetV2 模型完成图像分类推理，处理多格式图片的解码、缩放与归一化预处理；
    • 用户服务：实现邮箱验证码注册、JWT 鉴权（支持 Bearer 头与 URL 参数两种方式），Redis 缓存验证码与 Token；
    • 采用 Controller / Service / DAO 分层与工厂模式组织代码，GORM 操作 MySQL，配合缓存、消息队列与流式响应支撑高并发场景；
    • 使用 Docker Compose 一键编排后端、MySQL、Redis、RabbitMQ、ONNX Runtime，具备完整可上线运行能力。

    技术栈：Go、Gin、GORM、MySQL、Redis、RabbitMQ、RAG、Embedding、ONNX Runtime、Vue.js + Axios、Docker；后端采用 RESTful + SSE，前后端分离设计。
